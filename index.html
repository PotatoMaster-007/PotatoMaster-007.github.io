01 / IDENTIFICACIÓN

¿Qué es esta aplicación?

Esta aplicación corresponde al cliente OAuth creado por el propietario de este sitio en Google Cloud para autorizar su propia instalación local de rclone a utilizar la API de Google Drive.

El uso está limitado al propietario y a su cuenta personal. No se ofrecen cuentas a terceros, no existe un proceso de registro y el propietario no opera un servicio web que permita a otras personas gestionar sus archivos.

rclone es una herramienta de código abierto que se ejecuta en el dispositivo del usuario. Esta configuración utiliza un identificador de cliente OAuth propio para la autorización ante Google.

USO PREVISTO Una persona · Una cuenta personal

Acceso a Google Drive desde rclone instalado y ejecutado localmente por su propietario.

TIPO DE APLICACIÓN Cliente OAuth para aplicación de escritorio

La autorización se realiza mediante el flujo OAuth de Google utilizado por rclone.

03 / DATOS Y PERMISOS

Qué datos se utilizan y para qué

01

Autorización

rclone utiliza los tokens OAuth necesarios para obtener y renovar el acceso concedido por Google. Estos datos de autorización se guardan en la configuración local de rclone.

02

Archivos y metadatos

Según el permiso elegido, rclone puede consultar nombres, identificadores, carpetas y otros metadatos, así como leer o modificar el contenido de archivos.

03

Operaciones solicitadas

Los datos se utilizan para las operaciones que el propietario inicia, como listar, descargar, subir, copiar, sincronizar, mover o administrar archivos, siempre dentro de los permisos concedidos.

Los permisos dependen del alcance OAuth seleccionado.

Por ejemplo, el alcance drive permite acceso a los archivos de Drive (excepto la carpeta de datos de aplicaciones), mientras que drive.readonly limita el acceso a lectura. La autorización efectiva es la que se muestra en Google y está configurada en rclone.

04 / TRANSPARENCIA

Una configuración local y privada.

El propietario controla cuándo se ejecuta rclone, qué operaciones solicita y qué permisos concede. No hay un servidor propio que recopile o procese los archivos de Google Drive.
